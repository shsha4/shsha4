<h3>카카오워크 캘린더 운영 및 고도화</h3>

카카오워크의 주력 도구 서비스인 캘린더 시스템을 운영합니다.

- iCal · ICS 표준 기반 일정 가져오기/내보내기, 반복 일정, 화상 회의 연동, 구글 캘린더 공개 URL 동기화
- **Redis 캐싱 전략**으로 일간 1,500만~2,000만 건의 일정 조회 API 요청을 안정적으로 처리
- 일정 목록 조회의 **N+1을 Batch IN 조회로 개선**, 인덱스 튜닝으로 filesort · 임시 테이블 제거
- Node.js 프로세스의 높은 RSS를 분석해 **jemalloc 적용**으로 메모리 파편화 완화
- 비동기 클로저의 불필요한 객체 참조 제거 + `p-limit` 동시성 제어로 캐시 빌드 시 힙 급증 방지
- 유휴 DB 소켓 hang으로 인한 응답 유실을 분석하고, **커넥션 획득·반환 시점 소켓 타임아웃 전환**으로 해결
- Prometheus · Grafana 메트릭 모니터링 및 알림 연동
- **캘린더 AI Agent · MCP 서버** 구현 — 자연어 기반 일정 등록/수정/삭제/추천

<h3>카카오워크 데이터센터 이관 <sub>2024.12 – 2025.03</sub></h3>
